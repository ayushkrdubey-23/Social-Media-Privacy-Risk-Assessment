
# Social Media Privacy Risk Assessment Framework

## Overview

A defensive cybersecurity and privacy-awareness framework designed
to assess social-media privacy exposure, account-security practices,
social-engineering risks, and digital-footprint awareness.

## Project Objectives

- Assess social-media privacy practices.
- Identify personal-information exposure categories.
- Evaluate location and content privacy.
- Analyze account-security practices.
- Calculate category-wise privacy risk scores.
- Generate personalized security recommendations.
- Simulate privacy improvements.
- Visualize privacy assessment results.

## Technology Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Pandas
- Chart.js
- Pytest

## Ethical Scope

This project is designed for defensive cybersecurity and
privacy education.

It uses synthetic or voluntarily provided assessment responses.
It does not scrape, track, or profile real social-media users.
